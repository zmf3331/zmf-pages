## 1、Vsftpd介绍与安装

#### 1.1 Ftp协议

​	FTP（File Transfer Protocol，文件传输协议）是一种用于在计算机网络上进行文件传输的标准协议。它允许用户从一台计算机向另一台计算机上传或下载文件。FTP的工作原理涉及到客户端和服务器之间的交互，以及数据传输的过程。早期浏览器和windows资源管理器都支持直接打开ftp协议，后来因为安全问题禁止了

**01 Ftp的工作流程**

​	当FTP客户端要上传／下载文件时，通过与服务端21号端口建立于 TCP之上的控制连接，当服务端收到命令之后，立即进行验证或者响应（如：用户名和密码验证，文件传输命令等）。服务端收到文件传输命令时就需要和客户端建立一个数据连接通道用于传输文件，这个连接的建立可以由客户端主动发起，也可以由服务端发起。

​    数据连接并不是永久性存在的，一旦传输完毕就会将这个连接关闭掉，对于控制连接，只有关闭客户端控制连接才会随之关闭，控制连接是随客户端一起存在的。而数据连接是短暂存在的，只要文件／列表传输完成，数据连接就关闭了。

FTP协议有主动式和被动式两种工作方式，主动与被动是针对服务器是否主动发起数据连接而言的。



**02 Ftp主动模式（Port模式）**

​	在Port模式下，FTP 客户端首先和FTP服务器的TCP 21端口建立连接，通过这个通道发送命令，客户端需要接收数据的时候在这个通道上发送 `PORT` 命令。 PORT命令包含了客户端用什么端口接收数据。在传送数据的时候，服务器端通过自己的TCP 20端口主动连接至客户端的指定端口发送数据。 FTP server必须和客户端建立一个新的连接用来传送数据。

​	这个模式的问题在于，当客户端是内网设备时，通常有防火墙或NAT（网络地址转换）设备保护。来自外网服务器的连接请求，很容易被客户端的防火墙拦截导致数据连接失败。原因是主动模式的核心逻辑是服务器主动连接客户端且客户端的端口随机



**03 Ftp被动模式（Pasv模式）**

​	在Pasv模式下，FTP客户端首先和FTP服务器的TCP 21端口建立连接，通过这个通道发送命令。当客户端需要接收数据时，它在这个通道上发送 `PASV` 命令。服务器收到PASV命令后，会开启一个随机的高位端口（比如端口2024），并通过控制通道将这个端口号告诉客户端。在传送数据时，由客户端主动从自己的另一个随机端口，连接至服务器指定的那个随机端口，从而建立一个新的数据连接。

​	这个模式很好地解决了主动模式的问题，因为数据连接是由客户端主动发起的，可以顺利穿透客户端的防火墙或NAT设备。但其问题在于，服务器端需要开放一个随机的高位端口范围供客户端连接，如果服务器防火墙配置不当，只开放了21端口，被动模式的数据连接同样会失败。此外客户端或服务器使用NAT时，IP地址映射可能出现不一致，导致连接失败。

在实际使用中建议优先选择被动模式，开放服务器21端口和一个范围端口（如40000~65535）


#### 1.2 Vsftpd安装

Vsftpd是一个完全免费开源的ftp服务器软件，特点是小巧轻快，安全易用，支持虚拟用户，支持带宽限制。官网：https://security.appspot.com/vsftpd.html

一般来说各大Linux发行商的软件源都已内置了vsftpd，如果使用不了软件源可以去官网下载源码包

```bash
# apt -y install vsftpd tnftp
# wget https://security.appspot.com/downloads/vsftpd-3.0.5.tar.gz

$ yum -y install vsftpd ftp
$ rpm -ql vsftpd
/etc/vsftpd						# 配置目录
/etc/vsftpd/vsftpd.conf			# 配置文件
```

#### 2.1 全局配置

Vsftpd的配置涉及到的内容比较多，如监听地址与日志配置、运行模式配置、其他全局配置、用户配置、权限配置、兼容配置、证书配置。

**01 监听IP端口、日志配置**

```bash
# 需要注意,实际应用中vsftpd不支持在行内添加注释,启动会报错。只支持整行注释
listen=YES								# 开启网络地址监听
listen_ipv6=NO							# 不监听IPV6地址
listen_port=21							# 服务监听端口
idle_session_timeout=600				# 空闲会话超时时间(单位s)
use_localtime=NO						# 是否使用本地时区时间(默认显示为GMT)

# 日志配置
xferlog_enable=YES						# 开启日志
xferlog_std_format=YES					# 使用旧的wu-ftpd标准格式
xferlog_file=/var/log/xferlog			# wu-ftpd标准格式日志
dual_log_enable=YES						# 同时再写一份vsftpd自有格式日志
vsftpd_log_file=/var/log/vsftpd.log		# vsftpd自有格式日志文件路径
```

**02 主/被动模式配置**

```bash
# 主动模式配置
port_enable=YES							# 是否开启主动模式
ftp_data_port=20						# 主动模式中服务器用于发起连接的固定源端口(默认20)
connect_from_port_20=YES				# 主动模式是否固定使用特定端口来发起数据连接,如果YES则使用ftp_data_port指定的端口,NO则随机端口

# 被动模式配置
pasv_enable=YES							# 是否开启被动模式
pasv_min_port=40000						# 被动模式下,数据链接使用的最小端口
pasv_max_port=60000						# 被动模式下,数据链接使用的最大端口(实际使用的端口是最小端口到最大端口之间的范围)
pasv_address=ftp.zmf.org				# 当服务器位于内网时,它告诉客户端使用这个公网IP地址来建立数据连接,可以写成域名或IP
pasv_addr_resolve=YES					# 启动时动态解析pasv_address中指定的域名
```

**03 其他全局配置**

```bash
delete_failed_uploads=YES				# 删除上传异常的文件(但实测没有生效,不清楚)
ascii_upload_enable=YES					# 上传时是否默认使用ASCII模式传输,默认no（CRLF换行符转为LF换行符）
ascii_download_enable=YES				# 下载时是否默认使用ASCII模式传输,默认no
max_clients=1000						# 指定最大连接数
max_per_ip=100							# 每个IP的最大连接数(默认0不限制)
```



#### 2.2 用户配置

**01 本地用户模式和匿名用户模式**

-   本地用户模式就是让用户直接用Linux系统账号密码来登录FTP服务器
-   匿名用户模式就是访客模式，无密码（默认要输假密码）的方式，匿名用户名为 `anonymous` 或 `ftp`（需要注意虚拟用户映射的系统用户，对于禁锢根目录的权限）

```bash
# 本地用户模式配置(默认映射系统用户ftp)
local_enable=YES						# 是否允许本地用户登录
chroot_local_user=YES					# 将本地用户禁锢在它的家目录,无法浏览系统其他目录
allow_writeable_chroot=YES				# 被禁锢的根目录是否可写
write_enable=YES						# 用户登录是否允许写(所有用户通用选项,需要配合系统用户权限)
chmod_enable=NO							# 是否允许本地用户登录使用SITE CHMOD命令修改文件的权限
userlist_enable=YES						# 是否启用用户列表
userlist_file=/etc/vsftpd/user_list		# 指定用户列表访问控制文件,默认/etc/vsftpd/user_list
userlist_deny=NO						# 为YES时列表文件相当于黑名单。为NO时列表文件相当于白名单

# 匿名用户模式配置
anonymous_enable=YES					# 是否支持匿名用户
no_anon_password=YES					# 匿名用户是否完全需要密码
anon_world_readable_only=NO				# 启用时,将只允许匿名用户下载具有全球读权限的文件
anon_root=/var/ftp						# 设置虚拟用户的根目录
anon_upload_enable=YES					# 是否允许匿名用户上传文件
chown_uploads=YES						# 匿名用户上传文件时,是否允许将属主修改为指定的用户,如果为no默认为ftp
chown_username=ftp						# 设置匿名用户上传文件后的属主为指定的系统用户
chown_upload_mode=0644					# 设置匿名用户上传文件后的权限值
anon_umask=022							# 设置匿名用户权限掩码
write_enable=YES						# 用户登录是否允许写
anon_other_write_enable=YES				# 是否允许匿名用户删除/重命名文件
anon_mkdir_write_enable=YES				# 是否允许匿名用户创建目录
```

```bash
# 关于匿名用户的权限问题,Ftp对于匿名用户的权限限制是根目录不允许写
# 甚至文件系统上如果指定了根目录可写会报错：500 OOPS: vsftpd: refusing to run with writable root inside chroot()
# 如果想让匿名用户写,需要根目录设置只读,子目录可写
$ mkdir -p /var/ftp/pub
$ chown -R ftp.ftp /var/ftp
$ chmod 555 /var/ftp
$ chmod -R 755 /var/ftp/pub
```



**02 虚拟用户模式**

虚拟用户（Guest）是一种独立于系统账号、仅用于FTP服务的登录账户，通过映射到本地系统用户来操作文件，安全性更高。虚拟用户模式比较复杂，配置流程大体分为：

1.  准备Vsftpd虚拟用户配置
2.  准备用户名密码凭证、生成用户数据库、配置PAM
3.  准备虚拟用户子配置文件
4.  创建宿主机目录，确保映射用户的权限

```bash
# 虚拟用户登录配置
local_enable=YES						# 虚拟账户依赖本地用户框架,引用开启本地用户模式配置
chroot_local_user=YES					# 虚拟账户依赖本地用户框架,引用本地用户禁锢根目录配置
write_enable=YES						# 用户登录是否允许写

guest_enable=YES						# 启用虚拟用户模式
guest_username=vuser					# 指定虚拟用户默认映射的系统用户
pam_service_name=vsftpd.virtual			# 虚拟用户所使用的pam配置文件,指向的是/etc/pam.d/下的一个服务名
virtual_use_local_privs=YES				# 指定虚拟用户和本地用户一样的权限,否则会使用匿名用户的权限导致权限被拒绝
user_config_dir=/etc/vsftpd/conf.d		# 虚拟用户配置文件子目录(以虚拟用户名命名)
```

```bash
# 生成虚拟用户凭证.奇数行为用户名,偶数行为密码
$ vim /etc/vsftpd/vusers.txt
zmf
123456

# 生成用户数据库认证文件
$ db_load -T -t hash -f /etc/vsftpd/vusers.txt /etc/vsftpd/vusers.db
$ chmod 600 /etc/vsftpd/vusers.*

# 创建pam认证
$ vim /etc/pam.d/vsftpd.virtual
auth required pam_userdb.so db=/etc/vsftpd/vusers
account required pam_userdb.so db=/etc/vsftpd/vusers

# 生成虚拟用户子配置文件(以虚拟用户名命名)
$ vim /etc/vsftpd/conf.d/zmf
chroot_local_user=YES				# 引用本地用户禁锢根目录配置
guest_username=vuser				# 在虚拟用户子配置文件里也可以指定映射用户,优先级比全局配置文件里更高
local_root=/home/vuser/ftp			# 指定这个虚拟用户禁锢的根目录
write_enable=YES					# 用户是否可写
allow_writeable_chroot=YES			# 启用可写入的chroot根目录
local_max_rate=10485760				# 限制该用户的下载速度（单位:字节/秒,10485760=10MB/s）

# 创建对应的系统用户,并设置好权限
$ useradd -s /sbin/nologin vuser
# 确保安全,再将用户禁用
$ usermod -L vuser
$ mkdir /home/vuser/ftp
$ chown -R vuser:vuser /home/vuser
```

**03 后期增加虚拟用户**

要求增加一个虚拟用户，权限是root用户的权限，根目录锁在/root

```bash
# 添加一个虚拟用户v_root
$ vim /etc/vsftpd/vusers.txt
zmf
123456
v_root
123456

$ db_load -T -t hash -f /etc/vsftpd/vusers.txt /etc/vsftpd/vusers.db
$ chmod 600 /etc/vsftpd/vusers.*
$ vim /etc/vsftpd/conf.d/v_root
guest_username=root
local_root=/root
write_enable=YES
allow_writeable_chroot=YES
local_max_rate=10485760

$ systemctl restart vsftpd
```

#### 2.4 证书加密Ftps

需要注意，FTPS和SFTP不是一个意思，FTPS是“加了加密层的FTP”，而SFTP则是“SSH协议中的一个文件传输子系统”

```bash
# vsftpd证书配置
ssl_enable=YES									# 启用 SSL/TLS
allow_anon_ssl=NO								# 是否允许匿名用户使用SSL连接
force_local_logins_ssl=YES						# 所有的非匿名用户登录时都被强制使用SSL连接
force_local_data_ssl=YES						# 所有的非匿名用户传输数据时都被强制使用SSL连接
ssl_sslv2=NO									# 禁用不安全的SSLv2协议
ssl_sslv3=NO									# 禁用不安全的SSLv3协议
ssl_tlsv1=YES									# 允许TLS协议
ssl_ciphers=HIGH								# 允许使用HASH算法
# 指定RSA证书公钥和私钥文件
# 绝大部分场景使用的都是RSA证书,如果指定DSA证书,配置项为dsa_cert_file
rsa_cert_file=/etc/vsftpd/ssl/ftp.zmf.org.pem
rsa_private_key_file=/etc/vsftpd/ssl/ftp.zmf.org.key
```

>   ```bash
>   #!/bin/bash
>   # 生成测试证书Shell脚本
>   Domain="ftp.zmf.org"
>   ca_dir="/etc/vsftpd/ssl/ca"
>
>   mkdir -p ${ca_dir}
>   openssl genrsa -out ${ca_dir}/ca.key 4096
>   openssl req -x509 -new -nodes -sha512 -days 36500 -subj "/C=CN/ST=Beijing/L=Beijing/O=example/OU=Personal/CN=${Domain}" -key ${ca_dir}/ca.key -o
>   ut ${ca_dir}/ca.crt
>   openssl genrsa -out ${Domain}.key 4096
>   openssl req -sha512 -new -subj "/C=CN/ST=Beijing/L=Beijing/O=example/OU=Personal/CN=${Domain}" -key ${Domain}.key -out ${Domain}.csr
>   openssl x509 -req -sha512 -days 36500 -CA ${ca_dir}/ca.crt -CAkey ${ca_dir}/ca.key -CAcreateserial -in ${Domain}.csr -out ${Domain}.crt
>   cat ${Domain}.crt ${ca_dir}/ca.crt > ${Domain}.pem
>   chmod 600 ${Domain}.key ${Domain}.crt ${Domain}.pem
>   ```
